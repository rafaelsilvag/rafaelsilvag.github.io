Serviços de Redes para Internet.

Professor: Rafael Silva Guimarães

Da conectividade IP à entrega de software: construção, integração e operação de serviços com Docker, Docker Compose e CI/CD.

60 aulas enumeradas72 h carga horária total26 h teóricas46 h práticas

Aulas enumeradas como unidades de planejamento, com duração de 1 ou 2 horas. A distribuição soma 72 horas; a duração e o agrupamento dos encontros serão definidos no calendário. Não corresponde a 60 horas-aula de duração idêntica.

Um projeto, três etapas

O mesmo projeto evolui ao longo do semestre. No T1, a equipe planeja a rede e implanta containers. No T2, integra HTTP, DNS, aplicação web e banco de dados com Compose. No T3, automatiza testes, build, publicação e entrega para homologação, com monitoramento e recuperação.

Git e testes aparecem desde o início. O bloco de CI/CD consolida essa base em um pipeline com GitHub Actions. O ambiente de implantação será um host de laboratório ou uma máquina virtual definida para a turma.

Avaliações

Proposta de distribuição: 2 provas individuais e 3 trabalhos em grupo, totalizando 100 pontos. Datas, regras de recuperação, segunda chamada e aprovação serão definidas conforme as normas institucionais.
